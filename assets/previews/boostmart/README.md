# BoostMart — Warm Minimal Marketplace (Frontend Demo)

A standalone responsive HTML/CSS/JavaScript marketplace demonstration.

## Quick start
Open `index.html` in a browser. For local development, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Deploy to Vercel
Upload the **contents** of this folder using a static-site deployment, or import the folder into a Git repository and deploy as a static project (no build command required).

## Included functionality
- Responsive homepage and mobile navigation
- Search demo businesses by name, location and category
- Category filters and tabs
- Favourite businesses (saved in browser localStorage)
- Demo store detail modal
- Brand opening animation with stylised scratch transition, skip, and once-per-tab session behaviour

## Demo limitations
- All store names, descriptions and ratings are **fictional demonstration data**, not verified businesses.
- Store illustrations are emoji placeholders, not commercial product photography.
- Login, registration, business management, payments, admin dashboard, real reviews and real business data are **not implemented**.
- This is a standalone frontend starter, not a production-ready marketplace.
- The brand logo is included as an image supplied by the project owner; ensure ownership and resale rights before redistribution.
- Google Fonts are loaded from Google's font CDN and require internet access. Review font licensing and bundling for distribution.

## Customisation
- Edit colours in `styles.css` under `:root`.
- Edit categories and sample businesses at the beginning of `script.js`.
- Replace `assets/boostmart-approved-logo.png` with the final transparent brand logo if available.
- Add appropriately licensed store photography before selling the template.

## Files
- `index.html`: page structure
- `styles.css`: layout, responsive design and animations
- `script.js`: demonstration interactions
- `assets/`: branding image
- `product-info.json`: sample PRIMO Marketplace listing metadata
