Installation and scope

This is a source-code template, not a WordPress/Elementor theme or a single static HTML file. Node.js 22.13 or newer, dependency installation and a production build are required. Use the nextjs-source folder for Vercel or compatible Node.js hosting.

The booking form is an enquiry flow, not a live appointment or payment system. Configure your own receiving webhook before accepting submissions. Domain, hosting and external service fees are separate.

Illustrative imagery and licence information

Included imagery consists of illustrative design-reference studies. It is not an authentic portrait of GARFIW or evidence of actual client tattoo work. Replace it with authorised studio photography before commercial deployment.

Fonts load externally from Google Fonts. Commercial licence, support, updates and refund terms must be agreed with PRIMO before purchase. No exclusive rights to third-party assets are implied.

Frequently asked questions

Can I rebrand the template?

Yes. Edit the central content configuration, styling and imagery. Changing artist URLs also requires corresponding route and link changes.

Does the booking form send email immediately?

No. Configure an HTTPS receiving webhook and its server-side environment settings first.

Can I deploy it by dropping an HTML file into hosting?

No. This is a Next.js source application that requires installation and a build. Use the supplied installation guide.

Are the photographs actual tattoo client work?

No. The supplied photographs are illustrative design studies and should be replaced with authorised imagery.
